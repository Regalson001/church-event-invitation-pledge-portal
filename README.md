# Gather & Give — Event Invitation & Pledge Portal

A full-stack event invitation and pledge management application built
with Python, FastAPI, SQLAlchemy, SQLite, HTML, CSS and JavaScript.

## Features

- Professional responsive event invitation website
- Guest RSVP registration
- Attendance and guest-count tracking
- Pledge and contribution registration
- Live public event statistics
- Organizer dashboard
- Admin-protected endpoints
- Pledge status management API
- CSV report downloads
- SQLite database persistence
- REST API documentation

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Backend programming |
| FastAPI | REST API |
| SQLAlchemy | Database ORM |
| SQLite | Data persistence |
| HTML5 | Frontend structure |
| CSS3 | Responsive design |
| JavaScript | Frontend functionality |
